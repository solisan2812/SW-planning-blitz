# SW-planning-blitz

Versión estática del planning Nike Running para SportWear Plus. Incluye el catálogo, las referencias visuales de Tony Blee, las imágenes conceptuales generadas con IA y las locaciones de Blitz.

## Publicación

Este repositorio contiene la app lista para [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site). La fuente de publicación es la rama `main`, carpeta raíz (`/`). El archivo `.nojekyll` permite servir los archivos estáticos directamente.

Para actualizar este repositorio desde el proyecto de trabajo, ejecuta `python3 build_site.py` en la carpeta `instagram_tonyblee_30`, copia el contenido de `site/dist/` a este repositorio y publica un nuevo commit en `main`.

Los likes y cambios de categoría se guardan en el navegador de cada dispositivo. Usa **Descargar JSON** e **Importar JSON** dentro de la app para transferir esa selección entre dispositivos.

Las imágenes IA son conceptos de preproducción. Hay que revisar la fidelidad de cada artículo frente al producto físico antes de utilizarlas como material final de campaña.
