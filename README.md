# SW-planning-blitz

[Ver el planning publicado](https://solisan2812.github.io/SW-planning-blitz/)

Versión estática del planning Nike Running para SportWear Plus. Incluye el catálogo de 16 productos, 259 referencias visuales de 30 posts de Tony Blee, 52 imágenes conceptuales generadas con IA y locaciones de Blitz.

## Publicación

GitHub Pages publica la rama `main` desde la carpeta raíz (`/`). Los recursos de esta copia están reunidos en la raíz con nombres que conservan su carpeta de origen (por ejemplo, `generated__piece_01_01.jpg`). El archivo `.nojekyll` permite servirlos directamente.

Los likes y cambios de categoría se guardan en el navegador de cada dispositivo. Usa **Descargar JSON** e **Importar JSON** dentro de la app para transferir la selección entre dispositivos.

Las imágenes IA son conceptos de preproducción. Hay que revisar la fidelidad de cada artículo frente al producto físico antes de utilizarlas como material final de campaña.
